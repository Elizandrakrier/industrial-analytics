
# Industrial Analytics 🚀

Projeto desenvolvido para demonstrar competências em **Análise de Dados Industriais, Custos e Integração entre Produção e Finanças**. O objetivo da aplicação é traduzir indicadores de chão de fábrica em impacto financeiro direto para a gestão.

Você pode acessar a aplicação interativa rodando na nuvem através do link abaixo:
👉 [**Acessar Dashboard no Streamlit**](https://elizandrakrier-industrial-analytics-app-uzsky7.streamlit.app/)

---

## 🛠️ Tecnologias Utilizadas
- **Python**: Linguagem principal para automação e manipulação dos dados.
- **SQLite & Pandas**: Armazenamento leve de dados e modelagem/cálculo de indicadores.
- **Streamlit**: Criação do painel analítico interativo para web.
- **Plotly**: Visualização de gráficos dinâmicos.
- **OpenPyXL**: Rotina de exportação automatizada de relatórios.

---

## 📈 Principais Indicadores Calculados
1. **Eficiência de Linha**: Acompanhamento percentual do planejado versus realizado por ordem de produção.
2. **Impacto Financeiro do Refugo**: Tradução de peças perdidas em prejuízo monetário real.
3. **Desvio de Custo**: Monitoramento da variação entre o custo padrão e o custo real de produção.
4. **Análise de Paradas**: Identificação dos principais gargalos operacionais e motivos de horas paradas na fábrica.

---

## 📥 Funcionalidades
- **Filtros Dinâmicos**: Segmentação rápida por linha de produção.
- **Exportação de Relatórios**: Opção para baixar os dados tratados e filtrados instantaneamente em formato **Excel (.xlsx)** ou **CSV (compatível com Google Sheets)**, automatizando rotinas gerenciais.
